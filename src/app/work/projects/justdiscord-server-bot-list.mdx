## Tell a good server from a big one

Discord lists rank by member count, which tells you a server is popular, not that it is
worth joining. JustDiscord puts a score out of 5 on every listing and requires the reviews
to say what the score is *for* — so the ranking carries an argument, not just a number.

A few rules hold the place together:

- **Votes decide the order, over a rolling 30 days.** Count votes forever and the top of
  every list becomes a museum of what used to be good; a rolling window makes every listing
  keep earning its place.
- **Verified means one thing.** Anyone can submit a server or a bot; if you prove you own
  it, the listing is marked. Unverified entries are still listed — just not marked.
- **Sponsored placements are always labelled.** Paid position is visible as paid position.
- **The emojis, stickers and packs are free**, with no account needed to download them.

Servers can also be **bumped once an hour**, from inside the server, to show up in "Just
bumped".

## The catalogue

- **%justdiscord.servers%** server listings
- **%justdiscord.bots%** bot listings
- **%justdiscord.emojis%** emojis and stickers
- **%justdiscord.visitors%** unique visitors

Emojis and stickers can be downloaded as files or installed straight into a server you
manage, one click, without leaving the page.

## For developers

Listed bots get a real API rather than a badge:

- **Vote checks** — ask whether a given user voted in the last 12 hours.
- **Stat posting** — push server counts and command lists on a timer.
- **Vote webhooks** — signed callbacks when somebody votes, verifiable in one call.

All of it wrapped in [`@justdiscord/sdk`](https://github.com/justdiscordorg/sdk): official,
TypeScript, zero dependencies, ESM and CommonJS, Node 18+.

## Engineering notes

A catalogue this size is mostly a search and crawl problem. Listings are paginated and
filtered server-side, the sitemap is sharded across a dozen files because a single one
would not hold 100,000+ URLs, and the edge cache is scoped to crawler files and OG cards
only — the HTML itself stays dynamic, because the layout reads the session.

Every listing renders its own social card and its own structured data, and every translated
listing carries its locale so the canonical URL points at the right language instead of
collapsing back to English.

JustDiscord is not affiliated with, endorsed by, or sponsored by Discord Inc. It is a
directory of things on their platform.
